# Use cases — beyond school

OmniTech Chat is a **pattern**, not a school-only app: friendly UI + router + domain tools on your LAN.

## Original purpose

Give a non-technical academic user:

- Chat in the browser  
- Excel → branded multi-sheet forecast / variance packs  
- PPT / PDF / Word / Excel generation  
- Web research with sources  
- Without IDE, without public ChatGPT for internal files  

## Education (where it started)

- Forecast vs exam grade packs (AS / A2, cohort sheets)  
- Parent/teacher one-pagers (PDF)  
- Subject insight decks (PPT)  
- Syllabus / timetable / grading research (web search)  

## Textile & manufacturing (OmniTech home turf)

- Shift / quality Excel packs  
- SOP and audit PDFs  
- Buyer meeting decks  
- Policy Q&A + supplier web checks (LAN-only UI)  

## Finance & admin

- Recurring workbook generation  
- Board packs (PDF/PPT) from structured JSON specs  
- Variance-style sheets for any KPI ladder (not only grades)  

## IT / internal ops

- Runbook answers with optional web confirmation  
- Ticket → summary DOCX  
- Safe sandbox code interpreter for log snippets (careful with secrets)  

## HR / training

- Onboarding decks  
- Policy Word docs  
- Quiz / roster Excels  

## Agencies & freelancers

- Client deliverables on a private box  
- Multi-model routing without giving clients raw API keys  
- Branded outputs via tools  

## What to customize per industry

| Keep | Swap |
|---|---|
| Open WebUI + OmniRoute | Domain tool (your Excel pack schema) |
| Web Search + Files API pattern | Prompt/defaults in follow-up filter |
| Tool ACL for named users | Brand colours / cover titles |

## Anti-goals

- Not a public multi-tenant SaaS (unless you add auth, TLS, tenancy)  
- Not a replacement for Continue/IDE power users  
- Not “install DeepSeek Harness plugins into WebUI” — different runtime; port ideas as OWUI tools instead
